宠店 AI 管家 产品设计文档（V1.0 MVP 版）
版本说明：本版本为面向个人创业者的最小可用产品设计，不含宠物健康问诊模块，核心聚焦「预约排期 + 客户复购唤醒 + 试用装转化」三大私域运营场景，采用低代码 / 零代码技术栈即可快速落地，全程标准化交付，不支持单店定制开发，完美匹配「副业启动、资产沉淀、自动化睡后收入」的商业目标。
一、产品概述
1.1 产品定位
面向社区宠物店、夫妻店、小型宠物生活馆的轻量级私域运营自动化 Agent 工具。无需对接收银系统、无需复杂部署，老板通过简单录入即可实现「预约自动排期、老客自动复购提醒、试用装自动回访转化」，用 AI 替代人工完成 80% 的重复性客户运营工作，帮助小店提升复购率、降低人力消耗。
1.2 目标用户
核心用户：1-3 人社区宠物店、宠物洗护店、猫咖店主
用户特征：无专职前台 / 运营，老板身兼数职；微信私域是主要客户池；有提升复购的需求，但没时间、没方法做精细化运营；对工具的要求是「便宜、简单、开箱即用」，决策成本低
付费能力：年付费 300-1000 元，决策周期≤1 天
1.3 核心解决痛点
排期混乱低效：电话 / 微信预约杂乱，忙时漏单、忘单，手工登记档期易出错，客户到店等待体验差
老客流失严重：洗护、寄养等服务有天然周期，但人工跟进费时费力，客户不提醒就不来，沉睡客户无人唤醒
商品转化低效：试用装免费送出去后，无人工回访跟进，转化全靠客户自觉，新品、主粮销量难提升
营销能力薄弱：做活动没思路、写文案没灵感，想做私域运营但没有专业能力
1.4 设计原则
轻量优先：拒绝大而全，只做高频刚需核心功能，降低学习成本和部署门槛
自动化优先：所有可规则化的工作全部交给 AI，人工只做异常处理，最大程度减少商家操作
标准化优先：所有功能通用化设计，不接受单店定制开发，保证产品可批量复制
可沉淀优先：所有话术模板、规则逻辑、行业数据均可沉淀复用，持续优化产品壁垒
二、核心功能模块设计
2.1 基础模块：客户与宠物档案中心
所有功能的数据底座，用于存储客户与宠物基础信息，支撑后续自动化规则触发。
核心字段
客户信息：微信昵称、联系方式、到店次数、消费标签、客户等级
宠物信息：宠物姓名、品种、年龄、体重、洗护周期、上次服务时间、过敏史 / 特殊备注
录入方式
商家手动批量导入（Excel 模板一键导入）
客户扫码自助填写（预约 / 领试用装时自动归档）
服务完成后商家一键更新服务记录
AI 能力：自动根据宠物品种、年龄、历史服务记录，推荐默认洗护周期，无需商家手动设置
2.2 核心功能 1：智能排期与预约管理
替代人工前台，实现预约全流程自动化，降低漏单、错单率。
2.2.1 客户自助预约
商家生成专属预约二维码 / 链接，客户微信点开即可选择服务类型（洗护 / 美容 / 寄养）、预约时间、填写宠物信息
系统自动校验档期冲突，冲突时段自动置灰不可选，无需人工确认
预约成功后，自动给客户发送预约确认通知，包含到店地址、注意事项、预约时间
2.2.2 档期自动管理
商家后台可视化日历视图，清晰展示每日预约情况，支持手动调整、取消预约
支持设置每日接待上限、服务时长、午休时段，适配不同门店的接待能力
2.2.3 到店自动提醒
预约前 1 天 / 前 2 小时，自动给客户发送到店提醒，减少爽约率
预约完成后，自动更新宠物「上次服务时间」，同步触发后续复购提醒规则
2.2.4 服务记录自动归档
服务完成后，一键标记服务完成，自动生成服务记录存入宠物档案，支持备注本次服务情况
2.3 核心功能 2：复购自动化唤醒系统
产品核心卖点，基于宠物服务周期自动触发提醒，把一次性客户变成持续复购的会员。
2.3.1 三类自动唤醒场景
表格
触发场景	触发规则	核心话术逻辑
洗护周期提醒	距离上次洗护 / 美容达到预设周期（默认 21 天，可自定义）	温和提醒洗护周期到了，结合天气 / 季节给出养护建议，附带预约入口
寄养档期预告	节假日 / 开学季前 7 天，自动给有寄养历史的客户发预告	提前告知门店寄养档期，引导提前锁定名额，附带早鸟优惠
沉睡客户唤醒	距离上次到店满 90 天	发送专属回归福利券（如洗护立减 20 元），唤醒流失客户
2.3.2 AI 个性化话术生成
不是固定模板，而是基于「宠物品种 + 年龄 + 历史服务 + 客户标签」动态生成专属话术，避免模板化生硬感
支持多种语气风格：亲切日常型、专业养护型、活泼可爱型，商家可一键切换
自动匹配当月活动、优惠券信息，话术自然植入转化入口
2.3.3 发送方式
MVP 阶段：生成话术后，商家一键复制到微信发送（降低技术门槛，无需接口权限）
进阶阶段：对接企业微信 API，自动发送私聊消息 / 社群通知
2.4 增值功能：试用装智能回访转化
针对门店主粮、零食、保健品等实物商品，实现试用装发放后的自动化跟进，提升转化率。
2.4.1 试用装登记
客户领取试用装时，扫码填写宠物信息、领取的产品类型，自动归档至客户档案
支持按产品品类分类：主粮、零食、营养品、驱虫用品
2.4.2 节点化自动回访
T+1 天：首次回访，询问宠物适口性、食用反应，主打贴心关怀
T+4 天：二次跟进，询问食用感受，自然引导正装购买
T+7 天：意向跟进，对未明确拒绝的客户，推送专属优惠，促成交
2.4.3 AI 意向识别与分层
自动识别客户回复的意向程度：高意向（询问价格、购买方式）、中意向（觉得还不错）、低意向（不爱吃 / 暂时不买）
高意向客户自动推送正装购买链接 / 专属优惠码
低意向客户标记偏好，后续推送对应品类的活动信息
2.4.4 转化数据统计
自动统计各品类试用装的领取量、回访率、转化率，帮老板判断哪些产品值得主推
2.5 联动模块：营销素材一键生成
与「宠物门店营销素材库」打通，实现运营工具 + 营销素材的闭环。
做活动时，输入活动主题，一键生成对应朋友圈文案 + 海报提示词
节日、店庆节点自动推送活动方案 + 配套素材，商家直接使用
作为素材会员的增值功能，同时作为 AI 管家的配套能力，互相引流
三、技术架构与实现方案
3.1 整体架构（零代码 / 低代码栈，个人可快速落地）
采用「前端交互层 + Agent 核心层 + 数据存储层」三层架构，全部基于现有 SaaS 工具搭建，无需自主开发服务器、后端，单人 1-2 周即可完成 MVP 版本。
plaintext
前端交互层
  ├─ 商家端：H5管理后台 / 企业微信侧边栏
  └─ 客户端：预约表单 / 回访问卷 / 通知消息

Agent核心层（Dify/Coze 零代码搭建）
  ├─ 预约排期工作流
  ├─ 复购唤醒话术生成工作流
  ├─ 试用装回访工作流
  ├─ 行业Prompt库（宠物运营专属）
  └─ 规则引擎（周期触发、意向判断）

数据存储层
  └─ 飞书多维表格 / 轻量云数据库
      ├─ 客户与宠物档案表
      ├─ 预约档期表
      ├─ 服务记录表
      └─ 试用装跟踪表
3.2 核心技术选型
表格
层级	选型工具	选型理由
Agent 核心	Dify（优先）/ Coze	零代码可视化搭建工作流，支持多模型接入，可生成对外访问链接，权限管理完善，适合快速搭建 Agent 产品
前端表单	金数据 / 飞书表单 / 麦客表单	快速生成预约、登记问卷，支持数据自动同步到表格，无需开发

权限管理	Dify 自带用户体系 / 小鹅通	实现按账号开通权限、时长管控、自动到期，适配订阅制付费
3.3 核心 Agent 工作流设计（以复购唤醒为例）
触发条件：每日定时扫描数据库，筛选出「距离上次洗护满 21 天」「90 天未到店」的客户名单
数据拉取：自动提取对应客户的宠物信息、历史服务记录、客户标签
话术生成：调用大模型，传入行业 Prompt 模板 + 客户专属信息，生成个性化唤醒话术
内容审核：内置合规校验规则，确保话术无违规、无夸大、语气合适
结果输出：话术批量导出，按客户分类整理，商家一键复制发送；进阶版自动推送
效果回流：商家标记转化结果，数据回流优化 Prompt 效果
3.4 数据安全设计
所有客户数据存储在商家独立的表格空间，平台不做数据泄露、售卖
产品层面明确告知商家需征得客户同意后录入信息，符合个人信息保护要求
不采集敏感隐私信息，仅保留服务必要的基础信息
四、核心业务流程
4.1 客户自助预约全流程
客户扫码打开预约链接 → 选择服务类型、预约时间 → 填写宠物基础信息
系统自动校验档期 → 无冲突则预约成功 → 自动生成预约记录
系统自动给客户发送预约确认通知
预约前 1 天 / 2 小时，自动发送到店提醒
客户到店完成服务 → 商家标记服务完成 → 更新宠物服务时间 → 触发复购提醒规则
4.2 洗护复购提醒全流程
系统每日定时扫描宠物服务记录
匹配达到预设洗护周期的客户 → 拉取宠物与客户信息
AI 生成个性化提醒话术 + 预约入口
商家确认后一键发送给客户
客户点击预约 → 自动进入预约流程 → 完成复购闭环
4.3 试用装回访转化全流程
客户领取试用装 → 扫码登记产品与宠物信息 → 数据归档
到达 T+1/T+4/T+7 时间节点 → 自动触发对应回访话术
商家发送回访消息 → 客户回复后，AI 识别意向等级
高意向客户自动推送购买优惠 → 引导成交
所有回访数据、转化数据自动统计归档
五、产品交互说明
5.1 商家端（核心操作极简，5 分钟上手）
采用左侧导航 + 右侧内容的简约后台布局，核心功能一目了然：
首页仪表盘：今日预约数、本周复购提醒数、试用装转化率、核心数据概览
预约管理：日历视图查看档期，支持新增、修改、取消预约
客户管理：客户与宠物档案列表，支持搜索、标签筛选、批量导入
复购运营：待提醒客户列表、话术预览、一键发送、发送记录
试用装管理：试用装领取记录、回访进度、转化数据统计
素材中心：联动素材库，一键生成活动文案与海报提示词
设置中心：洗护周期自定义、营业时间设置、话术风格选择、账号管理
5.2 客户端（无感知，纯微信生态）
全程在微信内完成，无需下载 APP
预约、登记通过 H5 表单完成，操作步骤≤3 步
通知消息通过微信私聊 / 服务号推送，形式自然，无广告感

八、合规与风险控制
数据隐私合规
产品仅提供工具能力，不持有、不泄露商家客户数据，商家自主管理自有客户信息
明确提示商家需遵守《个人信息保护法》，征得客户同意后方可录入信息
宣传话术合规
所有宣传主打「提升运营效率、辅助客户管理」，不承诺具体营收增长、转化率提升数据
禁止使用「保证复购」「销量翻倍」等夸大表述
服务边界免责
明确产品为「运营辅助工具」，所有话术、方案仅供参考，最终经营决策由商家自行负责
不含任何宠物医疗、诊疗相关功能，不涉及兽药、医疗建议等合规红线
知识产权合规
所有 Prompt 模板、工作流为自主设计，避免侵权第三方产品功能与文案
