# 营销活动页简化设计

## 目标

将现有 `activity.html`（活动方案生成器）简化为"选平台 → 选方向 → 生成文案 → 复制发布"的极简营销工具，去掉复杂表单，只保留营销文案生成与发布记录的核心链路。

## 改动范围

- **前端**：`web/templates/activity.html` 重写
- **后端**：`web/app.py` activity 相关路由改造；新增 `/api/activity/generate` 和 `/api/activity/publish`
- **复用**：`content_engine/templates/` 现有 15 个模板不变；`core/llm.py` LLM 调用不变
- **不涉及**：客户管理、触达系统、内容日历、经营顾问等其他模块

## 架构与数据流

```
用户浏览器
  │
  ├─ GET  /activity          → 渲染页面（平台列表 + 方向列表）
  │
  ├─ POST /api/activity/generate
  │     { platform, direction, context? }
  │         │
  │         ▼
  │     LLM 生成文案（基于 content_engine 模板）
  │         │
  │         ▼
  │     返回 { title, body, channel }
  │
  └─ POST /api/activity/publish
        { title, body, channel }
            │
            ▼
        写入 ContentItem（status="已发布"）
            │
            ▼
        返回 { id, status }
```

### 平台与内容方向（复用现有模板）

| 平台 | 内容方向 |
|------|---------|
| 抖音 | 改造前后、洗护过程、知识科普、宠物日常、产品开箱 |
| 小红书 | 品种护理、避坑指南、产品测评、季节性护理、到店体验 |
| 朋友圈 | 改造前后、客户好评、节日问候、新品预告、宠物知识 |

## UI 设计

单页面三区域布局：

1. **顶部：选择区**
   - 平台选择：三个横向 tab（抖音 / 小红书 / 朋友圈），默认选中抖音
   - 方向选择：根据平台动态切换的横向选项卡片，默认选中第一个
   - 补充说明：可选文本输入框，用于指定产品、品种、活动等额外上下文
   - 生成按钮：点击后调用生成接口

2. **底部：结果区**
   - 平台图标 + 方向名称
   - AI 生成的标题 + 正文
   - "一键复制"按钮：复制标题+正文到剪贴板，toast 提示"已复制"
   - "标记已发布"按钮：写入 ContentItem，按钮变为"已发布 ✓"（灰色不可再点）

3. **交互细节**
   - 平台切换 → 方向选项即时刷新
   - 生成中 → 按钮 loading 态
   - 复制失败 → 降级为选中文本，提示手动 Ctrl+C
   - 生成失败 → 显示错误提示 + 保留已选内容 + 可重试

## 错误处理

| 场景 | 处理方式 |
|------|---------|
| LLM 调用失败 | 结果区显示"生成失败，请重试"，保留已选内容 |
| Credit 不足 | 结果区显示"本月额度已用完，请升级套餐" |
| 网络超时 | 同 LLM 调用失败处理 |
| 剪贴板 API 不可用 | 降级为选中文本，提示手动复制 |
