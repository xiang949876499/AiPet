# AI 助手界面改造：宠物店运营问答百科

**日期：** 2026-06-25
**状态：** 已实现
**类型：** 前后端同步增强

---

## 实现结果

- Vue SPA 的 AI 助手已改为「经营问答百科」：搜索式提问、8 类运营问题卡片、AI 回复复制/分享。
- 前端提问会携带场景分类 `category`；旧的仅 `question` 请求仍兼容。
- `AdvisorAgent` 已使用统一宠物门店运营专家 prompt，按「问题判断 / 建议动作 / 可复制话术 / 注意事项」回答，并保留医疗问题拒答边界。
- 覆盖测试：`tests/test_agents/test_growth.py`、`tests/test_web/test_frontend_split.py`。

## 目标

将现有 AI 助手界面改造为宠物店运营问答百科：搜索式单次问答 + 分类卡片引导，覆盖宠物店经营全领域。

### 交互逻辑

1. **搜索框自由输入** — 用户直接输入问题，回车或点「提问」提交
2. **分类卡片快捷填充** — 点击卡片中的推荐问题，自动填入搜索框并提交
3. **回答区域** — 展示 AI 结构化回答，提供一键复制按钮
4. **分类卡片始终可见** — 问答完成后卡片保留，方便继续追问

### 关键 UI 细节

- 分类卡片：4 列网格（宽屏）/ 2 列（窄屏/移动端）
- 每个卡片包含：图标 + 分类名 + 2-3 条推荐问题链接
- 搜索框居中突出，placeholder 可轮播推荐问法（如"客户说价格高怎么回应"、"周末活动怎么策划"）
- 回答区域以卡片包裹，区分于分类引导区
- 替换现有 advisor 视图的全部内容

## 三、后端 Agent 改造

### 当前逻辑（旧）

```
用户提问 → 关键词匹配（医疗 → 拒绝 / 召回 → 召回 prompt / 其他 → 价格 prompt）→ 返回
```

硬编码仅支持价格异议和客户召回两类问题。

### 改造后逻辑（新）

```
用户提问 → 医疗关键词检查（拒绝）→ 统一运营专家 prompt → 结构化回答 → 返回
```

### Agent 设计

**AdvisorAgent 改造（agents/growth.py）：**

1. **保留医疗边界** — `medical_keywords` 保持不变，涉及诊疗/用药的问题直接拒绝并建议就医
2. **去掉硬编码路由** — 不再按关键词分支选择 prompt，改为一个统一的运营专家 prompt
3. **统一 Prompt 模板**：
   ```
   你是宠物门店运营专家助手。你的任务是根据店主的提问，
   给出结构化的、可立即执行的建议。

   要求：
   1. 先理解问题核心，再给出分析
   2. 建议要具体、可执行，不空泛
   3. 涉及客户沟通时，提供可直接复制使用的话术
   4. 不做医疗诊断，不承诺治疗效果，不建议用药
   5. 语气亲切专业，像资深宠物店长在分享经验
   6. 回答控制在 200-400 字，结构清晰

   店主问题：{question}
   ```
4. **API 向后兼容** — `POST /api/advisor` 支持旧格式 `{"question": "..."}`，也支持 `{"question": "...", "category": "客户沟通"}`，响应仍为 `{"answer": "..."}`
5. **Fallback 机制** — 当 LLM 不可用时，返回通用建议文本

### 路由文件（web/routes/advisor.py）

无需改动，现有接口签名完全兼容。

## 五、边界与约束

- **医疗安全**：皮肤病、用药、呕吐、拉稀、发烧、诊断、治疗、疫苗反应 → 拒绝回答并建议就医
- **不承诺效果**：AI 回答不承诺经营效果、不承诺客户一定会回复
- **不自动执行**：所有建议需人工判断后执行，不自动群发、不自动私信
- **Credit 消耗**：沿用现有 credit 机制，每次问答消耗 1 credit
