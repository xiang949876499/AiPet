# 宠物店 AI 运营 Agent Phase 1 功能说明文档

> 基于 `docs/superpowers/plans/2026-06-22-pet-store-optimization-phase1-plan.md`、`docs/superpowers/specs/2026-06-22-pet-store-optimization-design.md` 和当前项目实现整理。

## 1. 产品定位

宠物店 AI 运营 Agent 是面向单店宠物店老板和店员的本地化运营工具。系统不替代收银、库存或医疗系统，而是聚焦门店日常私域运营：识别该维护的客户、生成可执行话术、规划自媒体内容、提醒店员跟进，并通过订阅与 License 激活形成可销售版本。

当前项目已具备 MVP 能力：客户/宠物/服务记录管理、复购提醒、试用装回访、AI/模板话术、内容草稿、7 天运营计划、订阅套餐、企业微信内部通知、CLI 与 Web 工作台。Phase 1 目标是在此基础上补齐商用闭环、自动触达、内容模板引擎和分层数据看板。

## 2. 用户角色

| 角色 | 主要诉求 |
|---|---|
| 门店老板 | 知道今天该联系哪些客户、该发什么内容、运营效果如何、订阅是否有效 |
| 店员 | 查看待跟进客户、复制/确认话术、处理推送任务 |
| 系统管理员/销售方 | 生成激活码、查看授权状态、停用/续费/升级 License |
| AI 运营系统 | 自动扫描客户机会、生成话术和内容、计算运营指标 |

## 4. 核心业务流程

### 4.1 License 激活流程

1. 用户购买后获得激活码。
2. App 启动时检查本地 License Token。
3. 无 Token 或 Token 过期时进入激活页。
4. 用户输入激活码、门店名称、手机号。
5. App 调用 License Server `/api/activate`。
6. License Server 验证激活码、绑定机器、签发 Token。
7. App 本地缓存 Token 与套餐信息。
8. 后续每 24 小时发送 `/api/heartbeat`。
9. 断网 7 天内允许继续使用，超过宽容期后锁定或降级。

### 4.2 客户触达流程

1. 每日定时扫描客户数据。
2. 根据规则识别洗护到期、沉睡客户、复购机会。
3. 系统按客户价值分层：
   - VIP 客户：生成话术，进入人工确认页。
   - 普通客户：满足规则后自动发送。
   - 免打扰客户：跳过。
4. 发送记录写入触达日志。
5. 看板统计发送数、回复率、到店转化率。

### 4.3 内容生成流程

1. 老板选择平台与模板，例如朋友圈洗护前后对比、小红书品种护理。
2. 输入宠物名、品种、服务亮点等变量。
3. 系统生成多版文案、话题标签和图片提示词。
4. 用户选择并微调。
5. 内容加入日历，按日期提醒发布。
6. 发布后可记录互动数据，用于增长版看板。

### 4.4 运营看板流程

1. 首页加载门店与订阅信息。
2. 系统生成/刷新今日提醒任务和内容草稿。
3. 根据套餐等级返回不同数据：
   - 入门版：今日触达、本月到店、待处理、本周收入。
   - 专业版：入门指标 + 转化漏斗 + 客户健康度 + 触达方式对比。
   - 增长版：专业指标 + LTV、流失预警、内容排行、月报。

## 7. 套餐分层

| 功能 | 入门版 | 专业版 | 增长版 |
|---|---:|---:|---:|
| 客户档案 | 支持 | 支持 | 支持 |
| 洗护/复购提醒 | 支持 | 支持 | 支持 |
| AI 话术 | 基础额度 | 更高额度 | 高额度 |
| 企业微信内部通知 | 不支持或受限 | 支持 | 支持 |
| 内容日历 | 不支持或受限 | 支持 | 支持 |
| VIP 确认流 | 不支持 | 支持 | 支持 |
| 自动触达规则 | 不支持或少量 | 2 条核心规则 | 全量规则 |
| 专业漏斗看板 | 不支持 | 支持 | 支持 |
| LTV/流失预警/月报 | 不支持 | 不支持 | 支持 |

## 8. 合规与边界

系统不提供宠物医疗诊断、用药建议、治疗建议或医疗图片识别。涉及疾病、健康异常、治疗方案的问题，应提示客户联系专业兽医或正规宠物医院。

客户侧外部消息发送必须遵守企业微信能力、客户授权状态、免打扰设置和发送频率限制。VIP 客户默认走人工确认，避免自动化触达伤害客户关系。

## 9. Phase 1 验收标准

- License Server 支持激活、验证、心跳、续费/升级基础能力。
- App 未激活时进入激活页，激活后可正常进入工作台。
- 本地 Token 支持 7 天离线宽容。
- 触达规则至少支持洗护到期和沉睡唤醒。
- VIP 客户进入确认流，普通客户可自动发送。
- 内容引擎至少提供朋友圈和小红书各 5 套模板。
- 内容可生成、保存、排期并在日历中展示。
- 看板按套餐展示不同层级数据。
- CLI、Web、定时任务均能触发核心流程。
- 测试覆盖 License、触达、内容、看板和端到端流程。
